# 🧠 YOLO11 Object Detection Web App

A Streamlit web application for real-time object detection using **YOLO11 (Ultralytics)**.
Users can upload images and instantly see detected objects with bounding boxes.

---

## 🚀 Features

- Upload images (`.jpg`, `.png`, `.jpeg`)
- Object detection using YOLO11
- Fast & lightweight YOLO11n model
- Clean Streamlit UI
- Easy deployment on Streamlit Cloud

---

## 🛠️ Tech Stack

- Python
- Ultralytics YOLO11
- Streamlit
- OpenCV
- PyTorch
